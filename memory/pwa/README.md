# PWA

## Responsabilidade

Definir a identidade e os assets usados quando o 9Router é instalado como aplicativo no Chromium/ChromeOS.

## Componentes

- [PWA](./PWA.md): manifesto e ícones de instalação.

## Relações

`src/app/manifest.js` publica os ícones de `public/icons/` no manifesto web da aplicação.
